The game is a top-down arena style game with infinity number of wave   
kill all the enemies to progress to the next wave
I used basic key configuration of WASD for moving, Q for healing and left_mouse to attack
for this project i used godot and gdscript
this is my first time creating a playable game even though it not the best game
when i started creating it i thought it gonna be really hard, but even though it wasn't easy it still was easier than I expected
I decide to start to work on this due to an event hosted by hack club
right now there is only one type of enemy, but I am planing to add more
